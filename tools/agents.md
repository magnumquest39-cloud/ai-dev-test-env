# Модули ИИ-агентов

| Агент | Назначение | Активация |
|-------|-----------|-----------|
| Plan Agent | планирование, чек-листы | сложные задачи |
| Code Agent | написание кода, IDE-интеграции | задачи кода |
| Research Agent | исследование, поиск источников | незнакомые области |
| Review Agent | ревью, поиск багов | перед интеграцией |
| Test Agent | тесты, регрессия | после изменений |
| Router Agent | выбор модели, агента, скилла | каждый запрос |

## Принципы делегирования

- Сначала поиск готового агента (searchAgent)
- Создание нового агента только при отсутствии готового
- Параллельный запуск независимых агентов
- Асинхронные задачи через runAsTask

## Автономные правила

- Среда сама выбирает лучшую бесплатную комбинацию ресурсов
- При ошибке: тест -> фикс -> ретест, до 5 итераций
- Платные элементы автоматически заменяются бесплатными
