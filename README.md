# AI Dev Test Environment

Тестовая среда разработки через ИИ-чат: адаптивный план работы,
автономные настройки, бесплатный тулкит и конвейер тестирования.

## Быстрый старт

| Файл | Назначение |
|------|-----------|
| PLAN.md | Адаптивный план работы |
| CONFIG/autonomy.json | Настройки автономности и бесплатности |
| CONFIG/overrides.json | Переопределение настроек (приоритет 999) |
| CONFIG/functions.json | Реестр функций и инструментов |
| tools/agents.md | Модули ИИ-агентов |
| tools/custom_tools.json | Пользовательские инструменты |
| tests/test_env.sh | Проверка окружения |
| run.sh | Точка входа |
| .github/workflows/test.yml | CI-тест |

## Принципы среды

1. Бесплатность: только бесплатные инструменты, модели и сервисы
2. Автономность: минимум подтверждений, только необратимые операции
3. Адаптивность: роутер выбирает модель, агента и скилл под задачу
4. Проверяемость: каждый модуль покрыт тестом

## Архитектура

ИИ-чат -> Роутер -> Агенты -> Инструменты -> Тесты -> Отчёт

## Запуск

bash run.sh
