# Адаптивный план работы (AI Dev Test Environment)

## 1. Режимы работы

- PLAN: задачи на 5+ шагов, проекты, интеграции
- CODE: написание, рефакторинг и оптимизация кода
- AGENT: делегирование специализированным под-агентам
- TEST: верификация и регрессионное тестирование
- AUTONOMIC: автономное исполнение с самокоррекцией

## 2. Роутер выбора ресурсов

1. Модель: бесплатные модели приоритетны, платные только по явному согласию
2. Агент: сначала searchAgent (workspace + market), иначе создание нового
3. Скилл: lobe-skill-store, searchSkill, importFromMarket
4. Параллельность: независимые агенты запускаются одновременно

## 3. Настройки автономности

Подтверждение требуется только для:
- удаление репозиториев и веток
- публикация в продакшен
- трата средств

Все остальные операции выполняются автоматически.
Ошибки исправляются итеративно: тест -> фикс -> повторный тест.

## 4. Политика бесплатности

- Полная замена платных элементов бесплатными аналогами
- Создание кода и программ по референсам без платных патчей
- Мониторинг лимитов и автоматический переход на бесплатные модели
- Блокировка платных вызовов без согласия пользователя

## 5. Цикл разработки

1. Разбор задачи
2. Выбор режима, моделей и агентов
3. Создание плана и чек-листа
4. Реализация модуля
5. Тест модуля
6. Ревью и исправления
7. Интеграция и регрессия
8. Отчёт и обновление плана

## 6. Переопределение настроек

CONFIG/overrides.json применяется последним:
- приоритет 999 над базовыми настройками
- добавляет или заменяет инструменты и функции
- управляет режимом, языком и политикой бесплатности

## 7. Критерии готовности

- все тесты PASS
- нулевая стоимость
- подтверждённая автономность
- документация актуальна
